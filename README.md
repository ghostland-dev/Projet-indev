# Alimbio

Final-year defence project: C# application for an organic food company.

## Features

- ASP.NET client
- Visual Studio solution

## Tech Stack

- C# / .NET

## Getting Started

```bash
git clone https://github.com/ghostland-dev/alimbio-defense-project.git
cd alimbio-defense-project
dotnet restore
dotnet run
```
